# АттендоСтуд

Веб-система учёта посещаемости студентов, разработанная на PHP (Laravel).

## Описание

АттендоСтуд — портал для колледжа/вуза, где преподаватели отмечают посещаемость по занятиям, а студенты видят свою статистику в разрезе предметов. Если количество пропусков превышает 10, строка подсвечивается красным.

## Технологии

- PHP 8.2 / Laravel 11
- MySQL
- Blade шаблоны
- CSS (адаптивная вёрстка, мобильная навигация)

## Возможности

- Регистрация и авторизация (роли: студент, преподаватель, администратор)
- Расписание занятий по группам
- Отметка посещаемости преподавателем по каждому предмету и дате
- Личный кабинет студента — статистика посещаемости по предметам (процент, пропуски, опоздания)
- Красная подсветка при превышении 10 пропусков
- Лента новостей с категориями
- Профиль пользователя (ФИО, группа, специальность)
- QR-пропуск для студентов
- Панель администратора — управление пользователями и новостями
- Кастомные страницы ошибок (404, 403, 500)
- Часовой пояс: Москва (UTC+3)

## Установка

```bash
git clone <repo>
cd attendostud
cp .env.example .env
composer install
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

## Структура БД

- `users` — пользователи (студенты, преподаватели, администратор)
- `schedules` — расписание (группа, предмет, преподаватель, аудитория)
- `attendances` — посещаемость (студент, занятие, статус, дата)
- `news` — новости и объявления
